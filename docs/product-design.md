# 夸夸工坊 · 产品设计文档

> 版本：v0.1（概念阶段） · 更新日期：2026-11-15

## 1. 问题定义

- 当代社会普遍存在「内耗」现象，人们缺少精神层面的滋养与被认可的体验。
- 一句具体的夸奖成本几乎为零，但情绪价值可以支撑一整天。
- 用户痛点：**很久没有收到来自别人的真诚夸奖**。

## 2. 需求验证

- 高校「夸夸群」现象（2019 年前后爆火）：用户愿意付费/互助换取一句夸奖，证明需求真实存在。
- 夸夸群的失败点：玩具式热闹，无沉淀、无留存、夸奖内容空洞。
- 我们的差异化：**夸奖基于真实发生的事**——「你今天把拖了两天的实验报告写完了，这种收尾能力很多人做不到」远比「你真棒」有价值。

## 3. 目标用户

- 大学生（首发人群）：社交压力大、情绪波动明显、乐于尝试轻社交产品。
- 延伸：职场新人、独居青年。

## 4. 核心功能

### 4.1 发布动态 📝
- 用户记录「今天做的一件小事」，一句话即可，降低表达门槛。
- 示例：今天主动举手回答了一个问题 / 把宿舍收拾干净了 / 跑了 3 公里。

### 4.2 熟人夸奖 👥
- 微信登录，好友可见动态。
- 夸奖支持**匿名 / 化名**（朋友取一个昵称来夸），化解「想被熟人夸但不好意思署名」的微妙心理。

### 4.3 陌生人夸奖 🌍
- 发布时选择可见范围：**仅熟人 / 仅陌生人**。
- 不想让熟人知道的事（考砸了、失恋了、emo 了）可以只投给陌生人，收获没有社交负担的善意与安慰。

### 4.4 AI 助夸 🤖（规划中）
两个 AI 嵌入点：
1. **首夸机制**：动态发布后 AI 立即基于内容生成一句具体、有依据的夸奖，保证「发布即有反馈」，解决冷启动空窗。
2. **夸奖助手**：帮不会夸人的用户把「挺好的」扩写成走心的夸奖；提供不同风格（温柔 / 幽默 / 严谨）。

## 5. 关键设计：隐私分级

```
发布动态 ──┬── 仅熟人可见 ──→ 熟人夸奖（可匿名/化名）
           └── 仅陌生人可见 ──→ 陌生人夸奖（无社交压力）
```

## 7. 商业化设想（远期）

- 免费为主，守住善意氛围
- 可能方向：AI 夸奖高级风格包、企业版（团队激励场景）

## 8. 风险与合规

### 8.1 ⚠️ 微信审核受阻记录（2026-11-20）

- **事件**：以个人主体注册小程序时，被腾讯判定「涉及社区谈话」拒绝。
- **原因**：「用户发动态 → 他人夸奖」属于 UGC + 社区互动，需**企业/个体工商户主体**才能申请社交类目，个人主体无法选择该类目。
- **应对决策**：
  1. **产品降级改造（主线）**：转型为「AI 夸夸日记」——用户记录小事 + AI 夸奖（走**工具类目**，个人主体可申请），一键生成夸夸卡片分享到微信聊天，朋友通过卡片在聊天中互动。站内无 UGC 社区，规避审核红线，核心体验（被熟人夸）保留。
  2. **体验版演示**：比赛阶段使用小程序体验版（添加体验成员即可），无需过审发布。
  3. **企业主体（远期）**：若日后正式发布社交版，挂靠学校双创基地/课题组的主体资质。

### 8.2 通用合规事项

- 内容安全：UGC 内容需接入微信小程序内容安全 API（msgSecCheck）；AI 生成内容同样建议过检
- 心理边界：涉及负面情绪内容时，需引导至专业心理援助渠道，避免替代心理咨询
