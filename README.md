# 夸夸工坊 ✨

> 每天一句夸奖，撑起一整天的好心情。

**夸夸工坊**是一个微信小程序概念项目：用户记录今天做的一件小事，收获来自熟人（可匿名/化名）或陌生人的真诚夸奖。让"被看见"变成一种日常。

## 为什么做这个

现代人普遍内耗、缺少精神层面的滋养。一句具体的夸奖成本几乎为零，但情绪价值可以撑一整天——**大家太久没有听到别人夸自己了**。

## 核心功能

| 功能 | 说明 |
|------|------|
| 📝 发布动态 | 记录今天做的一件小事（一件小事就够） |
| 👥 熟人夸奖 | 朋友点赞夸奖，支持**匿名或化名**，化解"想被夸但不好意思"的社交压力 |
| 🌍 陌生人夸奖 | 可将动态设为仅陌生人可见，收获没有社交负担的善意 |
| 🤖 AI 助夸（规划中） | AI 在发布后先送出第一句有依据的夸奖，保证"发布即有反馈"；也能帮不会夸人的人把"挺好的"扩写成走心的夸奖 |

## 设计亮点：隐私分级

同一条动态可选择「熟人可见」或「陌生人可见」——有些事不敢让身边人知道（比如考砸了想被安慰），但陌生人的善意没有社交压力，反而更真诚。
